# NYA — Nusaiba Tasnim Chura Portfolio

A responsive personal portfolio with the existing purple/orange visual identity, dark/light theme, animated details, six website concepts, service cards, process, toolkit, FAQ, contact form and oversized NYA footer.

## Run
Open `index.html` in a browser. Google Fonts require an internet connection.

## Project links
Each of the six project cards includes separate Repository and Live website links. Check the links on the deployed site before sharing it publicly.

## Privacy
The CV PDF has been kept unchanged as requested. The certificate section is a designed text/template preview; the original certificate image is not included in this package.

## Contact form
The Formspree endpoint is configured in `script.js` as `https://formspree.io/f/xgakpzjz`. The form has not been submitted as part of this package check; verify it with a test message from the deployed site.

## Edit
- Content and links: `index.html`
- Colours, layout and responsive behaviour: `style.css`
- Theme, animations, navigation and form submission: `script.js`
