# Nusaiba Tasnim Chura — Portfolio

A responsive personal portfolio for an aspiring frontend developer. The visual identity uses **NYA** as the small brand mark, with a deep purple base, the existing purple/orange button styling, a circular profile photo and restrained motion.

## Sections

1. Hero
2. About me
3. Projects
4. Skills
5. What I can build for you
6. Certificate
7. Contact (including CV download)
8. Footer

## Included features

- Responsive Bootstrap layout and mobile navigation
- Dark/light theme toggle (preference saved in the browser)
- Project filters for the GitHub repository and practice projects
- Subtle scroll reveal and back-to-top control
- Contact form that prepares an email in the visitor's default email app
- GitHub, LinkedIn, Instagram and Facebook links
- NYA favicon and basic SEO metadata
- Keyboard focus styles and reduced-motion support
